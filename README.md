## Tentang

Halo, aku **Gxyenn** — pembuat **Kyora**.

Aku mengerjakan Kyora dari nol: tampilannya, aplikasi Android-nya, layanan di belakangnya,
sampai pipeline rilisnya. Prinsipnya sederhana: **rapi, cepat, dan tenang** — tidak ada
tampilan yang berisik, tidak ada langkah yang tidak perlu.

Saat ini fokusku satu: membuat Kyora terasa enak dipakai setiap hari.

## Proyek unggulan — Kyora

<a href="https://github.com/Gxyenn/Kyora-app/releases/latest">

Jetpack Compose, lengkap dengan akun, koleksi, dan komentar per episode.
